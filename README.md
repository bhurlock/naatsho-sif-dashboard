# NAATSHO Worker SIF Dashboard

Public dashboard of significant injuries and fatalities (SIFs) and near misses among state DOT workers and contractors on state DOT projects, 2015 to present, compiled for NAATSHO.

Live page: https://bhurlock.github.io/naatsho-sif-dashboard/

Publicly reported incidents only. Counts are not complete and coverage varies by state. The page is rebuilt each morning from the NAATSHO SIF log; please do not edit index.html by hand, because the next refresh replaces it.
